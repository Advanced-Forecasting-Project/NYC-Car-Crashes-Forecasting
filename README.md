# NYC Motor Vehicle Collisions Forecasting

This repository contains our group project for the Advanced Forecasting course at IBS Budapest. We analyze motor vehicle collision data from New York City (NYPD Motor Vehicle Collisions dataset, NYC Open Data) to understand trends and seasonality in crash counts and to forecast future collisions.

The project covers data cleaning and aggregation into a time series, exploratory analysis of trend and seasonal patterns, and the comparison of forecasting models on a held-out test period.
